# P3 파생 지표 구현 결과

## 사용자 프롬프트 요약

- P2 채널별 정규화 CSV를 입력으로 사용하는 CPA·ROAS·전환율 계산
- 행별 비율 평균이 아닌 원천 지표 합계 후 비율 계산
- 0 분모, 필수 값 결측, VAT 기준 혼합, 전환 정의 혼합 시 계산 제외와 사유 제공
- 기본 채널·캠페인 집계와 P4 재사용을 위한 그룹 기준 분리
- P4 전주 대비 비교와 P5 문장 요약 제외

## 결정된 내용

사용자 결정 사항:

| 항목 | 사용자 결정 |
|---|---|
| CPA | 비용 합계 ÷ 전환 합계 |
| ROAS | 매출 합계 ÷ 비용 합계 |
| 전환율 | 전환 합계 ÷ 클릭 합계 |
| 집계 순서 | 원천 지표 합계 후 파생 지표 계산 |
| 기본 그룹 | 채널·캠페인 |
| 제외 기준 | 0 분모, 필수 값 결측, VAT 기준 혼합, 전환 정의 혼합 |
| 채널 제약 | GA4 CPA·ROAS 제외, 메타·GFA ROAS 제외 |

구현 세부 기준:

- 입력 그룹에 결측이 한 건이라도 있으면 부분 합계 대신 해당 합계 결측 유지
- VAT 기준 또는 전환 정의 혼합 시 그룹 전체 파생 지표 제외
- VAT 기준·전환 정의 결측 시 그룹 전체 파생 지표 제외
- 매출 정의 혼합 시 ROAS 추가 제외
- 매출 값이 있는 행의 매출 정의 결측 시 ROAS 추가 제외
- 내부 비율값 `roas`와 사람용 퍼센트 `roas_percent` 동시 제공
- `roas_percent = roas × 100`, 전환율도 동일 표기 관계
- CPA 소수 둘째 자리, 비율 소수 여섯째 자리, 퍼센트 소수 넷째 자리 반올림

## 실제 결과

### 인터페이스

`read_normalized_input(input_path)` → `aggregate_metrics(rows, group_by=("channel", "campaign"))`

- 입력: 채널별 `*_normalized.csv` 디렉터리 또는 단일 공통 스키마 CSV
- 병합 기준: 파일명 오름차순, `*_normalized.csv` 이름, 17개 공통 필드와 순서가 같은 파일만 허용
- 숫자 계약: 비음수 정수 또는 숫자 문자열. 소수·지수·특수값·잘못된 쉼표 표기 거부
- 그룹 계약: 비어 있지 않은 문자열. `None`·숫자·빈 문자열 거부
- 오류 위치: P2의 `source_file`과 `source_row_number` 우선 표시
- 출력: 원천 지표 합계·결측 건수, 의미 기준 목록, 파생 지표, 지표별 계산 불가 사유
- P4 재사용: `group_by=("date", "channel")` 등 집계 기준 교체 가능

CLI 실행 예시:

```powershell
python src/metrics/calculate_metrics.py output/normalized output/reports/derived_metrics.csv
```
