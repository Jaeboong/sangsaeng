# P4 전주 비교 구현 결과

## 사용자 프롬프트 요약

- P2 정규화 CSV 5개를 입력으로 사용하는 ISO 주간 전주 비교
- 동일 채널·캠페인·지표별 전주 값, 금주 값, 증감, 증감률 계산
- 원천 지표 합계 이후 CPA·ROAS·전환율 재계산
- 전주 0, 신규, 금주 미집행, 결측, 정의 불일치, 불완전 기간 구분
- 구글시트 `전주비교` 탭에 바로 사용할 수 있는 CSV 출력
- 성과 해석, 좋아짐·나빠짐 판단, 요약 문장 제외

## 결정된 내용

사용자 결정 사항:

| 항목 | 사용자 결정 |
|---|---|
| MVP 범위 | P4까지 구현 |
| 주간 기준 | ISO 주간, 월요일 시작·일요일 종료 |
| 비교 단위 | 동일 채널·캠페인·지표 |
| 계산 대상 | 비용·노출·클릭·전환·매출·CPA·ROAS·전환율 |
| 증감 | 금주 값 - 전주 값 |
| 증감률 | 증감 ÷ 전주 값 |
| 결측 처리 | 0 대체 금지 |
| 정의 일치 | 동일 VAT 기준·전환 정의·매출 정의 |
| 출력 위치 | `output/reports/weekly_comparison.csv` |
| 제외 범위 | 성과 맥락 해석과 요약 문장, 공통 구글시트 업로드 어댑터 수정 |

구현 세부 기준:

- 기본 금주: 데이터에서 월~일 7개 날짜가 모두 존재하는 최신 ISO 주간
- 기준일 지정: 기준일 현재 완전히 종료된 최신 ISO 주간
- 금주 시작일 지정: 월요일 날짜 직접 입력
- 파생 지표: P3 `aggregate_metrics` 재사용, 기간별 원천 합계 이후 재계산
- 증감률 내부 비율값: `0.1 = 10%`, 소수 여섯째 자리 반올림
- 정의별 영향 지표: VAT 기준은 비용·CPA·ROAS, 전환 정의는 전환·CPA·전환율, 매출 정의는 매출·ROAS
- 상태 코드: `comparable`, `previous_zero`, `new`, `current_not_run`, `excluded`
- 불완전 기간: 캠페인별 실제 날짜 수와 `period_warning` 제공

## 실제 결과

### 인터페이스

`build_weekly_comparison(rows, current_week_start=None, reference_date=None)`

- 반환값: 선택된 금주 시작일과 비교 행 목록
- 출력 행: 채널·캠페인·지표별 1행
- 출력 열: 주간 시작·종료일, 전주·금주 값, 증감, 증감률, 실제 일수, 상태, 제외 사유, 기간 경고
- 구글시트 `전주비교` 탭 업로드용 UTF-8 BOM CSV

CLI 실행 예시:

```powershell
python src/comparison/weekly_comparison.py output/normalized output/reports/weekly_comparison.csv
python src/comparison/weekly_comparison.py output/normalized output/reports/weekly_comparison.csv --reference-date 2026-07-26
python src/comparison/weekly_comparison.py output/normalized output/reports/weekly_comparison.csv --current-week-start 2026-07-20
```

### 제공 데이터 검증

| 항목 | 결과 |
|---|---:|
| 전주 | 2026-07-13~2026-07-19 |
| 금주 | 2026-07-20~2026-07-26 |
| 채널·캠페인 | 11개 |
| 비교 행 | 88개 |
| 비교 가능 | 60개 |
| 결측에 따른 제외 | 28개 |
| 신규·금주 미집행 | 각 0개 |
| 불완전 기간 경고 | 0개 |

채널별 비교 결과:

| 채널 | 전체 | 비교 가능 | 제외 |
|---|---:|---:|---:|
| GA4 | 24 | 6 | 18 |
| 카카오 모먼트 | 8 | 8 | 0 |
| 메타 | 24 | 18 | 6 |
| 네이버 GFA | 16 | 12 | 4 |
| 네이버 검색광고 | 16 | 16 | 0 |

제외 28개는 정규화 원본의 비용·노출·클릭·매출 결측 유지 결과. 0 대체 없음. 제공 데이터의 모든 캠페인에서 전주·금주 각 7일 확인.

네이버 검색광고 `NSA_여름 크루즈 프로모션` 예시:

| 지표 | 전주 | 금주 | 증감 | 증감률 |
|---|---:|---:|---:|---:|
| 비용 | 876,500 | 996,600 | 120,100 | 0.137022 |
| 전환 | 69 | 114 | 45 | 0.652174 |
| CPA | 12,702.90 | 8,742.11 | -3,960.79 | -0.311802 |
| ROAS | 49.070165 | 60.766606 | 11.696441 | 0.238362 |

수치 비교만 제공. 성과의 좋고 나쁨과 원인 해석은 P5 범위로 유지.
