# 설계 메모

### 문제 정의

#### P1. 채널별 리포트 수집

광고 채널 5곳의 관리자 화면에 개별 접속해 리포트를 내려받는 반복 작업. 채널 API 연동 자산이 없다는 과제 전제에 따라 MVP 범위에서 제외.

#### P2. 채널별 CSV 정규화와 구글시트 반영

채널마다 다른 컬럼명·날짜 형식·집계 기준을 사람이 구글시트에서 수동 정렬하는 작업.

정규화는 로컬 프로그램 내부에서 수행. 파일 헤더로 채널을 판별한 뒤 날짜·채널·캠페인·비용·노출·클릭·전환·매출의 공통 스키마로 변환. 원본에 없는 값은 결측으로 유지하고 VAT 기준과 전환 정의는 별도 정보로 보존. 원본 행 단위 변환을 기본으로 하며 날짜·채널·캠페인 중복은 자동 합산하지 않고 검증 대상으로 처리. 구글시트 업로드는 정규화 이후의 출력 단계로 분리. MCP는 개발과 검증의 보조 수단으로만 사용.

#### P3. 파생 지표 계산

CPA·ROAS·전환율을 매주 구글시트 수식으로 다시 계산하는 작업.

#### P4. 전주 대비 비교
계
기간별 데이터를 나누고 전주 대비 증감과 증감률을 수식으로 계산하는 작업.

#### P5. 주간 요약 보고

채널별 성과와 주요 변화를 사람이 선별해 요약 문장으로 작성하는 작업.

주요 변화의 중요도 판단과 성과 맥락의 해석이 필요한 영역. P4의 객관적 비교 결과를 사람이 검토해 최종 보고를 작성하는 방식으로 유지. 2시간 MVP 범위에서 제외.

### 구현 범위

- P1: 채널 API 연동 자산이 없다는 과제 전제에 따라 제외
- P2~P4: 데이터 정규화, 파생 지표 계산, 전주 대비 비교까지 구현
- P5: 사람의 판단이 필요한 요약 보고 영역. 도메인 지식이 필요하고 작성 보조는 가능하지만 판단 기준과 검토 절차에 대한 추가 설계가 필요하므로, 현재 방식으로 유지하고 제한 시간 내 구현 범위에서 제외

제한 시간 안에서 객관적 기준으로 반복 가능한 계산과 수작업 제거에 집중. 최종 해석과 보고 문장 작성은 자동화 대상에서 제외.


---
### 가정

1. 입력은 관리자 화면에서 수동 추출한 GA4·메타·네이버 검색광고·네이버 GFA·카카오 모먼트 CSV 5종. 채널 API 연동과 수집 자동화는 MVP 범위에서 제외.
2. 제공 데이터는 실제 리포트 구조를 재현한 가상 값. 파일 구조와 지표 차이만 설계 근거로 사용. 값 자체를 근거로 한 사업 성과 판단은 제외.
3. 정규화 결과의 공통 식별 정보는 날짜·채널·캠페인. 원본 행 단위 변환과 추적 정보 보존. 원본에 없는 값은 0이 아닌 결측으로 유지.
4. 채널별 전환 지표는 원본 정의 유지. GA4 주요 이벤트와 광고 채널 구매 전환은 별도 지표로 관리.
5. ROAS는 동일 리포트에 비용과 매출이 모두 있는 경우에만 계산. GA4 매출의 개별 광고 매체 배분은 제외.
